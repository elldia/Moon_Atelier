개인정보처리방침

Moon Atelier (달빛서재) · 최종 수정일: 2026-10-02

개요

Moon Atelier(달빛서재)는 별도의 서버 없이 동작하는 앱입니다. 개발자는 사용자의 개인정보를 수집·저장·전송하지 않으며, 앱이 다루는 모든 데이터는 사용자의 기기(또는 브라우저) 안에만 남습니다.

저장되는 데이터와 저장 위치

사용자가 추가한 책/만화 파일, 북마크, 형광펜(하이라이트), 폴더, 읽기 설정 등은 기기의 로컬 저장소에만 저장됩니다(웹 버전은 브라우저의 IndexedDB, 안드로이드 버전은 기기 내부 저장소). 이 데이터는 어떤 서버로도 전송되지 않으며, 개발자를 포함해 그 누구도 접근할 수 없습니다. 브라우저 데이터를 지우거나 앱을 삭제하면 함께 삭제됩니다.

선택적 외부 연동

  • Dropbox / OneDrive: 파일을 가져오려면 각 서비스의 공식 로그인 페이지에서 로그인하고 앱에 파일 읽기 권한을 허락합니다. 비밀번호는 해당 서비스의 페이지에만 입력되며 앱은 볼 수 없습니다. 앱은 허락받은 임시 접근 토큰으로 파일 목록을 보여주고 사용자가 고른 파일을 내려받는 데에만 사용하며, 토큰을 기기에 저장하지 않고 개발자를 포함한 어떤 서버로도 보내지 않습니다(앱을 닫으면 사라집니다). 웹 버전의 Dropbox는 Dropbox가 제공하는 공식 선택 창(Chooser)을 사용합니다. 각 서비스에서의 처리는 해당 서비스의 개인정보처리방침을 따릅니다.
  • FTP 서버 / 같은 Wi-Fi 기기 간 전송: 사용자가 직접 주소를 입력하거나 같은 네트워크의 다른 기기와 연결하는 기능으로, 개발자가 운영하는 서버는 관여하지 않습니다.

이 기능들은 모두 사용자가 직접 실행해야만 동작하며, 자동으로 실행되지 않습니다.

백업 파일

서재 백업(내려받기/메일 공유)으로 만들어지는 zip 파일은 사용자가 선택한 위치에만 저장되며, 개발자는 그 사본을 받지 않습니다. 백업 복원 역시 사용자가 직접 고른 파일을 기기 안에서만 처리합니다.

음성으로 듣기(TTS)

기기 또는 브라우저에 이미 설치된 음성 엔진을 사용하며, 읽어주는 텍스트를 외부 서버로 전송하지 않습니다.

외부 링크

개발자 후원(Buy Me a Coffee, 웹 버전만), Windows용 프로그램 다운로드(GitHub Releases) 등 일부 버튼은 누르면 외부 웹사이트로 이동합니다. 그 사이트에서는 해당 사이트 자체의 개인정보처리방침이 적용됩니다.

권한(안드로이드)

인터넷 권한은 위에서 설명한 선택적 연동 기능(Dropbox/OneDrive/FTP/같은 Wi-Fi 기기 간 전송), 아래의 외부 리소스 내려받기에만 사용되며, 앱이 자체적으로 개인 데이터를 어디로도 전송하지 않습니다.

외부 리소스

일부 기능은 필요할 때 외부 서버에서 공개 리소스를 내려받습니다. 이때 다른 웹사이트에 접속할 때와 마찬가지로 기기의 IP 주소 등 기본적인 접속 정보가 해당 서버에 전달될 수 있습니다. 책 내용이나 사용자가 추가한 파일은 전송되지 않습니다.

  • Google Fonts: 읽기 설정에서 일부 글꼴(노토 산스, 나눔고딕 등)을 고르면 Google Fonts 서버에서 글꼴 파일을 내려받습니다.
  • jsDelivr(CDN): 악보(MusicXML) 표시 엔진을, 웹 버전에서는 PDF 표시 엔진(pdf.js)도 이 서버에서 불러옵니다.
  • Dropbox: 웹 버전은 Dropbox 선택 창 스크립트를 Dropbox 서버에서 불러옵니다.

아동의 개인정보

이 앱은 특정 연령층을 대상으로 하지 않으며, 앞서 설명한 대로 애초에 수집하는 개인정보가 없습니다.

Privacy Policy

Moon Atelier (달빛서재) · Last updated: 2026-10-02

Overview

Moon Atelier runs without any backend server. The developer does not collect, store, or transmit any personal data — everything the app handles stays on your own device (or browser).

What's stored, and where

Books/comics you add, bookmarks, highlights, folders, and reading settings are stored only in your device's local storage (the browser's IndexedDB on the web version, on-device storage on Android). None of it is ever sent to a server, and no one — including the developer — can access it. It's deleted if you clear your browser data or uninstall the app.

Optional third-party integrations

  • Dropbox / OneDrive: to import a file, you sign in on that service's own official sign-in page and allow the app to read your files. Your password is entered only on the service's page; the app never sees it. The app uses the temporary access token you grant only to list your files and download the one you pick — it never saves the token on your device or sends it to any server, the developer's included, and it's gone once the app is closed. On the web version, Dropbox import uses Dropbox's own official Chooser. Each service's own privacy policy applies to what happens on its side.
  • FTP servers / Wi-Fi transfer between your own devices: you enter the server address yourself, or connect to another device on the same network — no server run by the developer is involved.

All of these only run when you explicitly start them; none of them run automatically.

Backup files

A library backup (download or email share) is saved only wherever you choose — the developer never receives a copy. Restoring a backup likewise only processes the file you pick, entirely on your device.

Text-to-speech

Uses the voice engine already installed on your device or browser. The text being read is never sent to an external server.

External links

A few buttons — "Buy Me a Coffee" (web version only) and the Windows-app download (GitHub Releases) — open an external website when tapped. That site's own privacy policy applies once you leave the app.

Permissions (Android)

The Internet permission is used only for the optional integrations above (Dropbox/OneDrive/FTP/Wi-Fi transfer) and for downloading the external resources below — the app never uses it to send personal data anywhere on its own.

External resources

Some features download public resources from outside servers when needed. As with visiting any website, basic connection details such as your device's IP address may reach those servers. Book contents and files you add are never sent.

  • Google Fonts: choosing certain reading fonts (e.g. Noto Sans, Nanum Gothic) downloads the font files from Google Fonts' servers.
  • jsDelivr (CDN): the MusicXML sheet-music engine is loaded from it, and on the web version the PDF engine (pdf.js) as well.
  • Dropbox: the web version loads the Dropbox Chooser script from Dropbox's servers.

Children's privacy

This app isn't directed at any specific age group, and as described above, it doesn't collect personal data from anyone in the first place.
